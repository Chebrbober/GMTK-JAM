# Kutkatana 

About the game:

Slice food before the countdown reaches zero. Land perfect cuts, build combos which will grant you rush mode, and survive as the knife gets faster and faster.

Every 25 secs, a random event (frozen zone) appears. Cut at the frozen zone and you will slow time.
